BROWS.ASYA — сайт brow studio

КАК ОТКРЫТЬ
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для публикации загрузите всю папку Brows.Asya на хостинг (например, Netlify или GitHub Pages).

ЧТО ВНУТРИ
- index.html — структура сайта
- style.css — оформление и адаптивность
- script.js — анимации, мобильное меню и форма заявки
- assets/ — ваши фотографии

ПЕРЕД ПУБЛИКАЦИЕЙ
- Добавьте Instagram/WhatsApp и реальные контакты в footer и настройте прямую ссылку для записи.
- Уточните цены и длительность процедур в блоке «Услуги».
- При необходимости замените тексты на свои.
- Шрифты Google Fonts загружаются из интернета; при отсутствии соединения используются системные запасные шрифты.

Форма заявки сейчас формирует и копирует текст сообщения. Она не отправляет данные на сервер и не сохраняет персональные данные.
